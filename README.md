👨‍💻 **My Personal Portfolio Website**

This is my **Personal Portfolio Website** made using **HTML, CSS, and JavaScript**.
I made this project **myself** to showcase my **skills, projects, and resume**.
I kept everything **simple and easy to understand**.


💡 **How to Use**

1. Open **index.html** in any browser
2. **Home section** shows my name, introduction, and profile picture
3. Use the navigation bar to move to:

   * **About Me**
   * **Projects**
   * **Contact**
4. Scroll smoothly between sections
5. Contact form works with **JavaScript validation**


📄 **Sections Included**

### 🏠 Home

* Name, short introduction, profile picture
* Navigation links

### 👤 About Me

* Education, personal info, hobbies
* Organized with HTML and CSS

### 💼 Projects

* Project titles, descriptions, and images
* Styled using CSS Grid

### 📞 Contact

* Form with name, email, subject, message
* Validates inputs with JavaScript


✨ **Features I Added**

* Responsive design for mobile, tablet, desktop 📱💻
* Smooth scrolling navigation
* Hover effects on buttons and images
* Clean layout
* Resume download button (PDF)
* Flexbox and Grid layouts
* Simple interactive UI elements


🛠️ **Technologies Used**

* **HTML5** – Semantic tags like `<header>`, `<section>`, `<nav>`, `<footer>`
* **CSS3** – Flexbox, Grid, media queries, hover effects
* **JavaScript** – For interactivity (all JavaScript is written directly inside the `index.html` file; no separate JS file was created)


🧠 **What I Learned**

* How to structure a website using HTML
* How to make a responsive, clean layout with CSS
* How to add basic interactivity with JavaScript
* How to organize files properly
* How to present myself professionally
